Glifos de línea 24×24 con trazo redondeado, en el espíritu minimalista de la marca.

El consumidor aporta `name` (ver `Icon.AVAILABLE`: chevron-right, check, x, menu, mail, phone, map-pin, message-circle, search, users, target, bar-chart, trending-up, arrow-up-right), `size`, `color` (por defecto `currentColor`; `var(--primary)` sobre claro) y `title` si el icono significa algo. Sin `title` queda oculto a lectores de pantalla.
