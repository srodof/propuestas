Botón flotante circular rojo con la marca de WhatsApp, para abrir conversación directa.

Colócalo fijo en la esquina inferior derecha. El consumidor aporta `href` (enlace de WhatsApp) y opcionalmente `tooltip`, que también es su nombre accesible. Usa `radius-full` y `primary` con hover/active; es el único elemento flotante del sistema. No añadir sombra.
