Variación con flecha: sube, baja o sin cambio, coloreada por si el resultado es bueno o malo.

El consumidor aporta `value` (solo el texto, "30%"; la flecha la dibuja el componente), `direction` y `tone`. Una bajada de costo es `tone="good"` con `direction="down"`. La flecha es un SVG y lleva texto oculto con la dirección; nunca dependas solo del color.
