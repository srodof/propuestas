Tabla de datos de reporte con encabezado en mayúsculas y filas separadas por línea suave.

El consumidor aporta `columns` (`[{key, label, align}]`) y `rows` (objetos por clave; `_strong: true` pone la fila en negrita, como el Total). Las cifras se alinean a la derecha. Puede llevar `Delta` dentro de una celda.
